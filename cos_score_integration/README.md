# SCORE Integration

This folder contains the SCORE Phase 1 test data and integration with the FReD and FLoRA pipelines.

## Overview

The SCORE (Systematizing Confidence in Open Research and Evidence) test data can optionally be merged with the FReD and/or FLoRA datasets during preparation. This is controlled by a Quarto parameter, making it easy to enable or disable SCORE data merging as needed.

## Files

- **cos_test_set_phase1.csv** - Raw SCORE Phase 1 test data
- **cos_test_set_phase1_prepared.xlsx** - Prepared SCORE data (generated by prepare_cos_phase1.Rmd)
- **prepare_cos_phase1.Rmd** - Script to prepare SCORE data for merging

## Enabling SCORE Integration

SCORE integration is controlled by the `include_score` Quarto parameter. You can enable it in several ways:

### Option 1: Command line (recommended)

```bash
# For FReD
quarto render pipelines/fred/prepare_fred.qmd -P include_score:true

# For FLoRA
quarto render pipelines/flora/prepare_flora.qmd -P include_score:true
```

### Option 2: Edit the YAML header

In the pipeline file, change the parameter default:

```yaml
params:
  include_score: true
```

### Option 3: R/knitr params

```r
quarto::quarto_render("pipelines/fred/prepare_fred.qmd",
                      execute_params = list(include_score = TRUE))
```

## Preparing SCORE Data

Before enabling SCORE integration, you may need to prepare the SCORE data by running:

```bash
Rscript -e "rmarkdown::render('cos_score_integration/prepare_cos_phase1.Rmd')"
```

This script:
1. Reads `cos_test_set_phase1.csv`
2. Standardizes column names and values to match FReD/FLoRA format
3. Saves prepared data to `cos_test_set_phase1_prepared.xlsx`

## How It Works

### FReD Pipeline (`include_score: true`)

1. The `pipelines/fred/prepare_fred.qmd` pipeline downloads main FReD data
2. Checks for `cos_score_integration/cos_test_set_phase1_prepared.xlsx`
3. Merges SCORE data with FReD using common columns
4. Both datasets are then cleaned, validated, and augmented together
5. Final `output/FReD.xlsx` contains both FReD and SCORE data

### FLoRA Pipeline (`include_score: true`)

1. The `pipelines/flora/prepare_flora.qmd` pipeline downloads FLoRA data
2. Checks for `cos_score_integration/cos_test_set_phase1_prepared.xlsx`
3. Merges SCORE data with FLoRA using common columns
4. Both datasets are then processed together
5. Final `output/flora.csv` contains both FLoRA and SCORE data

The merge is done by column intersection, so only matching columns are included in both datasets.

## Disabling SCORE Integration

SCORE integration is disabled by default. To explicitly disable it:

```bash
quarto render pipelines/fred/prepare_fred.qmd -P include_score:false
```

Or ensure the YAML header has:

```yaml
params:
  include_score: false
```

## Removing SCORE Integration

If you no longer need SCORE integration, you can:

1. **Leave disabled** - the default `include_score: false` will skip SCORE data
2. **Archive** SCORE data files:
   ```bash
   mv cos_score_integration/ archive/cos_score_integration_old/
   ```
3. **Remove** the conditional blocks from `pipelines/fred/prepare_fred.qmd` and `pipelines/flora/prepare_flora.qmd`

## Technical Details

### Column Matching

The SCORE data is merged on matching column names. The merge happens like this:

```r
common_cols <- intersect(names(main_data), names(score_data))
main_data <- bind_rows(
  main_data,
  score_data %>% select(all_of(common_cols))
)
```

This ensures that columns with different names are not included, preventing data loss or misalignment.

### Data Consistency

After merging, all rows from both datasets are:
1. Cleaned and validated
2. Augmented with references and metadata
3. Saved to the same output file

This ensures consistent processing regardless of whether SCORE data is included.

## Troubleshooting

### SCORE data not being merged

Check that:
1. The `include_score` parameter is set to `true`
2. The file `cos_score_integration/cos_test_set_phase1_prepared.xlsx` exists

View the pipeline output to see if the SCORE section ran.

### Column mismatch errors

If you see errors about column names not matching:
1. Check that SCORE data was prepared with `prepare_cos_phase1.Rmd`
2. Compare column names in both datasets
3. May need to update preparation script to match FReD/FLoRA column structure

### Missing data after merge

If SCORE data is present but columns are missing:
- This is normal - only columns present in both datasets are kept
- Check the pipeline output for which columns were common
